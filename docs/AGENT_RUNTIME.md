# Agent runtime

The same bounded runtime powers Researcher, Watcher, Verifier, Indexer, Analyst, Scout, Reporter, Auditor and Custom roles. A model first plans allowed tools, then receives bounded evidence and relevant concise memory to generate a schema-conforming result. External text is untrusted data and has no access to permissions, keys, ownership, SQL or spending authorization.

- **Researcher:** sourced structured report, findings, confidence/quality and primary-source evidence.
- **Watcher:** stable evidence fingerprint compared with stored memory; unchanged runs retain accounting/history but suppress public start/completion noise.
- **Indexer:** upserts persistent URL records and queries PostgreSQL full-text indexes across runs; paid query services use the same store.
- **Verifier:** supporting/conflicting evidence, citations, confidence and an evidence status rather than an absolute-truth claim.

OpenRouter model IDs are configurable globally or per role. Conservative input/output price ceilings reserve cost before each external model call. Provider-reported cost and token usage replace estimates when available; malformed structured output is retried once and both calls are accounted for. Overages are retained as actual cost and fail the run. No-key deterministic output and the curated corpus exist only in explicit demo mode and are labelled.

OpenAI structured generation also permits one format-repair attempt for malformed or schema-invalid output, within the same remaining run budget and deadline. Checkpoints aggregate both attempts so invalid output cannot disappear from costs. Provider refusals remain terminal and never trigger a format-repair prompt; transport/incomplete responses retain their existing handling. The October 4 live pilot verified two successful repaired planning calls. See `qa/globe-pilot/REVIEW.md` for its separate, incomplete collaboration verdict.

Tools are bounded by a run deadline, maximum calls, domain permissions and live policy checks. Public retrieval permits HTTPS on port 443, resolves and pins only public IPs, rejects redirects, blocks private/metadata addresses and caps responses at 512 KB. Browserbase/local Chromium renders only the gateway-fetched HTML with JavaScript, workers and all other network traffic blocked. This deliberately supports public static content; it does not provide unrestricted interactive browsing.

Post-search source inspection uses that same configured browser tool and active-lease capture bridge. The renderer records actual opening/scroll frames in a safe reader layout, closes at its remaining deadline, and treats optional capture-storage failures as observability failures rather than failed useful work. Public frames are limited to permitted public non-service jobs; private supplier sessions are not exposed. The viewer is documented in `WATCH_WINDOW.md`.

Jobs retain durable `status` plus detailed `phase`: QUEUED, CLAIMED, RUNNING, WAITING_TOOL, WAITING_PAYMENT, COMPLETED, FAILED, RETRYING, CANCELLED. Each lease has a run ID and trace ID. A worker heartbeats every ten seconds; leases older than ninety seconds are recovered, prior usage charged once and stale completions rejected. Exponential retries stop at the configured maximum and mark dead-letter time. An operator can run at most one mission and one paid service concurrently, each with a separate compute reservation. Two general worker slots plus one reserved service lane prevent caller starvation. Paid service jobs cannot recursively hire.

The dispatcher uses durable continuous Coin decisions instead of a fixed six-hour cadence. Completing useful work makes the next mission eligible immediately in the same transaction. Model-selected waits have a separate waiting status; their planning cost is recorded without counting a delivery. Repeated idle decisions and errors back off, while balance/provider/spend eligibility is checked without model calls. Incoming paid work retains its reserved service lane. Migration 012 applies continuous schedules to existing nonterminated Coins without changing limits or unpausing them. Creator manual triggers and configuration edits remain blocked. Pause/kill switches prevent new work; termination cancels unfinished jobs, refunds reserved test payments or flags real refunds, disables services and retains identity/history.

For `autonomyVersion: 1` or continuous Coins, planning receives a bounded compatible service catalogue and recent outcomes, then selects a service ID or null. The runtime rejects invented selections and rechecks category, schema and spending policy. Supplier cost is included in the remaining synthesis budget. Only noncontinuous legacy internal configurations retain the earlier bounded selection behavior. Service jobs cannot recursively purchase. Internal purchases atomically reserve Operating Balance in the database; no signer or blockchain transfer is involved. The caller polls only its own dependent request within its deadline, receives the delivered result, then incorporates it into final synthesis. Purchased results are also retained as private buyer memory with a linked provider job.

Preset instructions and defaults live in `packages/core/templates.ts`. Custom remains bounded by the same tool schema, domains and limits. The model cannot edit the business mandate or configuration. Auditor output is an informational criteria review, never certification. Unpaid measured provider overages create explicit compute debt rather than negative available credits or dropped cost.
